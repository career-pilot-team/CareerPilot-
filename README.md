## 1. 사용자 프로필 관리
사용자 기본 정보 저장
관심 직무, 기술스택, 목표 직무 입력
MySQL DB 기반 JWT 인증과 계정 관리

## 2. AI 기반 진로/학습 추천 (FastAPI)
FastAPI + OpenAI API 기반 AI 추천 엔진이 제공:

### 추천 항목
- 추천 직무(Job Role)
- 필요한 기술 스택(Tech Skills)
- 추천 자격증(Certifications)
- 단계별 성장 로드맵(Tracks & Tasks)
- 직무 핵심 역량 분석 및 부족한 역량 안내

### 데이터 저장
Node.js 백엔드에서 AI 응답을 DB에 저장

## 3. 성장 트래커 (AI 로드맵 기반)
AI가 추천한 Tracks/Tasks 를 기반으로:

- 해야 할 일(To-Do) 체크
- 완료율 계산
- 그래프/도넛 차트로 성장 현황 시각화

## 4. 이력서 자동 생성
AI 추천 결과 + 사용자 프로필을 기반으로 PDF 이력서를 자동 생성하는 기능입니다.

### 주요 기능
- AI 기반 이력서 요약 생성 (자기소개, 핵심 기술, 경력 요약 등)
- 사용자 프로필 + 추천 결과를 결합한 구조화된 이력서 생성
- PDF 파일 자동 생성 및 다운로드 지원
- JWT 인증 기반 사용자별 이력서 관리

### 기술 요소
- Node.js에서 PDFKit 또는 pdfmake 기반 PDF 생성
- Express 라우터를 통한 파일 다운로드 API 제공
- Docker 환경에서 PDF 파일 생성 및 관리


## 5. 관심 공고 저장 / 개인 피드 추천 (추가 기능 예정)

- 사용자가 관심 있는 공고 저장
- 관심 공고 기반 개인화 추천 피드 생성
- AI 기반 "지원 가능성 분석" 기능 예정
